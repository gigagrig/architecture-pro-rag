## Задание 2. Подготовка базы знаний

### Выполнено

- Подготовлен скрипт загрузки и очистки материалов из Wikipedia.
- Созданы 38 уникальных документов об отдельных сущностях.
- Подготовлен словарь из 162 замен имён, организаций, планет, рас и технологий.
- Сохранён список исходных страниц и сведения о лицензии.
- Проверено отсутствие в документах исходных терминов из словаря.

### Проблемы

Стандартная среда не имела доступа к MediaWiki API. После выдачи сетевого доступа все 38 источников были загружены без ошибок. Других проблем, помешавших выполнить задание, не осталось.

## Задание 3. Создание векторного индекса базы знаний

### Выполнено

- Установлены `sentence-transformers` и CPU-сборка PyTorch.
- Документы разделены на 189 чанков по 100–250 слов с перекрытием 40 слов.
- Сгенерированы нормализованные эмбеддинги размерностью 768.
- Построен FAISS `IndexFlatIP` и сохранены метаданные чанков.
- Выполнены три поисковых запроса; во всех случаях правильная сущность заняла первое место.

### Проблемы

Во время первой проверки обнаружились одиночные исходные имена и один дублирующий документ после редиректа Wikipedia. Словарь и набор источников были исправлены, база и индекс пересобраны. Нерешённых проблем нет.

## Задание 4. Реализация RAG-бота с техниками промптинга

### Выполнено

- Реализован модуль RAG с существующим FAISS-индексом и тем же E5-энкодером.
- Добавлены few-shot примеры, краткое пошаговое обоснование по фактам и проверка цитат.
- Созданы API на FastAPI и Telegram-бот, который обращается к этому API.
- Токен проверен через Telegram: бот `@StarWarsRagExampleBot` доступен, webhook отсутствует. Токен не выводился и не добавлялся в Git.
- Загружен локальный кеш эмбеддингов; проверен поиск по семи вопросам.
- Выполнены 22 автоматических теста API, RAG и обработчика Telegram с подменой внешних сервисов. Все тесты прошли.
- Подготовлены скрипт проверки семи реальных ответов API и отдельная инструкция проверки через Telegram.
- Собран Docker-образ `quantumforge-rag:task4`; конфигурация Compose проверена. В контейнере проверены импорт API и зависимостей, чтение индекса из 189 фрагментов и отсутствие токена в образе.

### Проблемы

Для реальной генерации пока не выбраны LLM и параметры подключения. У пользователя запрошены модель и путь к файлу API-ключа либо адрес локального сервера. Поэтому реальные диалоги с LLM и проверка из Telegram пока не выполнены; ожидаемые ответы в инструкции не выдаются за фактические результаты.

В песочнице сетевые запросы были недоступны, а TestClient зависал на межпоточном обмене. После разрешённого запуска вне песочницы проверка Telegram, загрузка модели и автоматические тесты прошли.
