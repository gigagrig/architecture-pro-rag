## Задание 4. Реализация RAG-бота с техниками промптинга

### Выполнено

- Реализован модуль RAG: загрузка FAISS-индекса из 189 фрагментов, E5-энкодер, поиск, few-shot примеры, краткое обоснование и проверка дословных цитат.
- Подключена Yandex Alice AI LLM Flash: `gpt://b1g2bu1h99h8aoj25qf5/aliceai-llm-flash/latest`. Генерация выполняется через Chat Completions со структурированным JSON, эмбеддинги вычисляются локально.
- Работают FastAPI (`POST /ask`, `GET /health`, `/docs`) и Telegram-бот [@StarWarsRagExampleBot](https://t.me/StarWarsRagExampleBot), использующий тот же API.
- Настройки сведены к одному `docker-compose.yml` с двумя сервисами — API и ботом. Ключ Yandex и токен Telegram подключаются через отдельные secrets, исключены из Git и образа.
- Выполнены 24 автоматических теста API, RAG, HTTP-клиента модели и обработчика Telegram с подменой внешних сервисов. Все тесты прошли.
- Приёмка через реальный API: 7 из 7 сценариев прошли — пять ответов с источниками и два корректных отказа.
- Подготовлены [реальные диалоги через API](task4_dialogues.md), [машиночитаемый отчёт](task4_api_results.json) и [инструкция ручной проверки Telegram](TELEGRAM_TESTING.md).
- Docker-образ пересобран, API и Telegram polling запущены. Переписка пользователя в Telegram не считывалась и не выдаётся за автоматическую проверку.

### Проблемы и решения

Первоначально два полезных ответа превращались в «Я не знаю»: модель меняла текст цитат или относила их к другому фрагменту. Усилены требования к копированию цитат и добавлена одна попытка исправления по тем же найденным документам. Невалидные цитаты по-прежнему отклоняются; проверка источников не ослаблена.

При последующей проверке модель вернула цитату длиннее ограничения контракта. Запрос переведён с произвольного JSON на схему `GeneratedAnswer`; ограничены инструкции по длине и содержанию ответа. Сетевые ошибки и некорректный формат остаются технической ошибкой HTTP 503, а не маскируются под отсутствие знаний.

Проверка семи вопросов является учебной приёмкой, а не гарантией качества на произвольных запросах. Проверка цитат подтверждает их наличие в найденных документах, но не доказывает все утверждения ответа. Демонстрация prompt injection относится к заданию 5.
